# Profiling Firefox for Android

Two options are possible:

- [Remote Profiling Firefox for Android](/user/guide-remote-profiling) provides the most options but can be cumbersome to set up;
- [Profiling Firefox for Android directly on the device](/user/guide-profiling-android-directly-on-device) has fewer options but should be easier to set up.
